# 教學原理｜跨週次課堂報告互評

這個專案包含 **GitHub Pages 單頁網頁** + **Google Apps Script 資料接收程式**。不必建立伺服器或資料庫；學生填寫後直接寫入教師的 Google 試算表。

## 學生會看到什麼？

每週只能選擇當週兩組之一，並填寫 **1 至 30 字心得**。學生頁面只顯示組別與主題，不顯示組員名單，也不要求填姓名。

| 報告日 | 開放期限（臺灣時間） | 選項一 | 選項二 |
| --- | --- | --- | --- |
| 2026/11/23 | 11/23–11/29 | 第 1 組：工作分析教學法 | 第 2 組：協同教學法 |
| 2026/12/7 | 12/7–12/13 | 第 3 組：探究教學法／講述教學法 | 第 4 組：直接教學法 |
| 2026/12/14 | 12/14–12/20 | 第 5 組：討論教學法 | 第 6 組：結構式教學法 |

> 開放時間會依「Asia/Taipei」自動判斷。未開始與已截止的週次仍能查看主題，但無法提交；無須每週修改程式。

## 安裝：依序做這 4 步

### ① 新增 Google 試算表

在 [Google 試算表](https://sheets.google.com) 建立空白檔案，例如命名「教學原理｜報告互評（2026）」。**請保留試算表為私人檔案，不要公開分享編輯權限給全班。**

### ② 設定 Apps Script

從這份試算表選取 **擴充功能 → Apps Script**，開啟 `Code.gs`，刪除原始預設文字，貼上本資料夾內 [`Code.gs`](Code.gs) 的全部內容，按儲存。

在編輯器上方函式選單選擇 **`setup`**，按下 **執行**，依提示授權。它會自動建立：

- **互評回覆**：每份學生送出的時間、日期、週次、獲選組別、主題、心得與提交編號。
- **統計總覽**：六組各自的獲選票數，以及占該週有效填答的比例（自動更新）。

`setup` 可以重複執行；不會刪除已收到的互評資料。請勿手動改動「互評回覆」表中第 1 列標題或刪除第 G 欄，以免影響統計、防重送功能。

### ③ 部署成網頁應用程式

在 Apps Script 編輯器右上角選擇 **部署 → 新增部署 → 選取類型「網頁應用程式」**，設定：

- **執行身分**：我（擁有此試算表的教師）。
- **誰可以存取**：任何人（Anyone）。

按 **部署**，複製 **網頁應用程式網址**，其結尾通常為 `/exec`。開啟這個網址，若看到「教學原理互評資料接收端已啟用」，表示已部署。

若學校 Workspace 管理規定不允許設為「任何人」，匿名網頁可能無法使用此方式；需改採機構允許的驗證機制。

### ④ 將網頁放到 GitHub Pages

打開 `index.html`，找到靠近檔案底部的這行：

```js
const WEB_APP_URL = "PASTE_YOUR_GOOGLE_APPS_SCRIPT_EXEC_URL_HERE";
```

將雙引號中的字串換成剛複製的完整 `/exec` 網址後儲存。

前往 GitHub，新建一個公開 repository，例如 `teaching-principles-vote`，**只需上傳 `index.html`**。進入 **Settings → Pages → Build and deployment**，將 Source 設為 **Deploy from a branch**，Branch 選 **main**、資料夾選 **/(root)**，按 Save。

稍後 GitHub Pages 會出現可分享的網址，形式通常是：

`https://你的帳號.github.io/teaching-principles-vote/`

學生直接用手機開啟即可，沒有帳號或登入欄位。

## 注意事項

- **匿名便利性與一人一票不同**：本版不向學生收集姓名／學號，完成提交後會在同一瀏覽器顯示已填寫，也會避免同一次網路重送造成重複記錄；但學生若換裝置、無痕模式或清除瀏覽器資料，仍可能再次投票。**無法嚴格保證每位學生每週只能投一次。** 若成績或正式投票會使用結果，建議增加學校登入或一次性代碼。
- `index.html` 的畫面限制以及 `Code.gs` 的後端驗證，都會阻止提前提交／超過截止日提交，並限制只能選當週的兩組與 1–30 字心得。
- 如果需要延長繳交時間，應同時修改 `index.html` 的 `WEEKS[].end` 以及 `Code.gs` 的 `VOTE_WEEKS[].end`，並**重新部署 Apps Script 的新版本**、更新 GitHub 上的 `index.html`。
- 網頁不收集姓名或學號；回覆表中的「提交編號」只是隨機的網路重送識別碼，不是學生身分驗證。Google 平臺本身仍可能留存一般技術性使用紀錄。
- 不要將 Google Sheet 設成可由全班編輯；GitHub Pages 僅需公開 `index.html`，**不要把任何教師 Google 帳號憑證放到網頁中**。

## 檔案說明

- **`index.html`** — 學生端畫面、週次、選組別、30 字心得、回執提示；唯一需上傳 GitHub 的檔案。
- **`Code.gs`** — Google Sheet 端接收與統計產生程式；只需貼到綁定試算表的 Apps Script。
- **`README.md`** — 本設定說明。
