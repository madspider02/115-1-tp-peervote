**GitHub 上的 `index.html` 不需要更新**，因為它只是嵌入 Apps Script 頁面。保留原有 34 人資料與報告當週免評設定。

# 教學原理｜跨週次報告互評 v5（34 人正式名單、報告當週免評）

**這版修正前一版「無法取得查詢結果」的設計問題。** 舊版 GitHub 的 HTML 透過隱藏跨網域表單與 iframe 等候回覆；v5 改成 **Apps Script 直接提供學生填寫頁面並以 `google.script.run` 讀寫 Sheet**。GitHub Pages 只嵌入這個頁面並提供「直接開啟」的備援入口，因此不必透過跨網域表單傳遞查詢結果。

## 已包含的規則

- 34 位學生，已配對學號與姓名，依教師原先的六組名單判定組別。
- 學生輸入學號及姓名並與正式名單核對；**姓名與學號不符不能進入**。
- 當週報告的兩組學生 **免填當週互評**：
  - **11/23** 第 1、2 組免填（11 人）；其餘 23 人需互評，開放 **11/22 00:00 ～ 11/24 23:59**。
  - **12/7** 第 3、4 組免填（12 人）；其餘 22 人需互評，開放 **12/6 00:00 ～ 12/8 23:59**。
  - **12/14** 第 5、6 組免填（11 人）；其餘 23 人需互評，開放 **12/13 00:00 ～ 12/15 23:59**。
- 每位需填學生每週選一組並留下 **至少 30 字**的心得（無另外設定上限）；不能修改或重複投票。
- 隔週可檢視自己的歷次心得（唯讀）。
- **報告當週免填**不會被記為未繳；不會將免填學生的資料寫成假投票。
- 系統時間以 **Asia/Taipei** 為準，後端會再次驗證開放期限。

1. **先備份**原來的 Google Sheet。從同一個 Sheet 點「擴充功能 → Apps Script」。
2. 在 **`Code.gs`** 把舊程式**整份替換**成這個資料夾的新版 `Code.gs`。如果還有別的 `.gs` 檔包含舊版 `doGet`、`getDashboard` 或 `submitPeerVote`，請避免重複定義。
3. 在 Apps Script 左側「檔案」旁按「＋」→「HTML」，名稱輸入 **`Vote`**；開啟新增的 `Vote.html`，**整份貼上**本資料夾 `Vote.html` 的內容。**不要把 Vote.html 傳到 GitHub。**
4. 按「儲存」。在編輯器上方的函式下拉選 **`setup`**，按「執行」，授權程式使用 Google 試算表。成功會建立／更新三個工作表：`互評回覆`、`互評正式名單2026`、`統計總覽`。既有 `學生名單` 完整保留。**不清空既有回覆**；舊匿名資料會保留但無法關聯個人。
5. 先檢查 `互評正式名單2026`：34 位同學的姓名、學號、組別及免評週次都應出現。可再於編輯器執行 **`checkSetup()`**，檢查名單與 Sheet 連結（不會新增投票）。

## 排除錯誤

- **畫面仍顯示舊版**：先開上方 `/exec`，如果它也顯示舊版，就必須編輯 Apps Script 原部署並選「新版本」。如果 `/exec` 已是新版、GitHub 仍是舊版，代表尚未替換 `index.html`。
- **畫面寫「找不到 HTML 檔 Vote」**：請在 Apps Script 專案中新增 HTML 檔案，名稱填 `Vote`，並貼上 `Vote.html` 全部程式。
- **畫面寫「教師尚未執行 setup()」**：請回 Apps Script 編輯器執行 `setup()`，完成授權後重新整理。
- **學號與姓名不符**：請核對 `互評正式名單2026`，名單已預填 34 位學生；既有「學生名單」不會被修改；新的正式名單如有相同姓名但不同學號，setup() 會停止並提示教師核對。
- **GitHub 中空白或不接受互動**：GitHub 頁面下方有「直接開啟互評表」連結，使用 Apps Script 網址即可。少數瀏覽器可能限制第三方嵌入，直接開啟可避開此問題。
- **仍顯示舊的「無法取得查詢結果」**：代表學生仍開啟舊版 GitHub `index.html`（它才有跨域表單逾時訊息）；**v5 已不使用該跨域查詢方法**。

## 資料保護提醒

- `Code.gs` 中有全班 34 人的姓名與學號，請只放在教師管理的 Apps Script 專案裡，**不要放進公開 GitHub repository**；Google Sheet 也不宜設定為公開可檢視。
- 目前「姓名＋學號」只能識別學生，**不構成強式登入驗證**。知道同學完整姓名與學號的人可能冒用身分查看其歷次心得。如要把這個互評納入正式成績，建議進一步使用學校帳號登入或為每人發放私密驗證碼。
- 本機已進行程式邏輯測試與模擬網頁測試；**未使用教師的正式 Apps Script 權限，也未對真實 Google Sheet 送出測試資料**。部署後需要由教師確認實際查詢與寫入狀況。
