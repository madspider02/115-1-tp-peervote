# 教學原理互評 v7.0：GitHub 原版單頁（2026 秋季）

這版回到原本的使用方式：學生開啟 **GitHub Pages**，直接填 **學號、姓名**，在同一網頁完成互評、查看上週心得。**不會轉到 Google Apps Script 網站**、不使用整頁 iframe、也不需要 Vote.html。

## 你只需要更新兩個檔案

| 放哪裡 | 檔名 | 用途 |
| --- | --- | --- |
| Google Sheet → 擴充功能 → Apps Script | `Code.gs`（貼到原本的 `程式碼.gs`） | 學生身分核對、投票、日期限制、儲存與讀取 Sheet |
| GitHub 儲存庫 `madspider02/115-1-tp-peervote` 根目錄 | `index.html` | **學生看到的完整原版互評頁面** |

**不要新增 `Vote.html`。** 舊專案已存在的 `Vote.html` 可暫時留著，不會被新版使用。**不要刪除 Google Sheet 的任何既有工作表或互評回覆。**

## 設定順序（請先完成後端，再更新 GitHub）

1. 打開原 Google Sheet → **擴充功能 → Apps Script**。
2. 點左側原本的 `程式碼.gs`，整份替換為此包的 `Code.gs`，儲存。若以前有 `Vote.html`，不用動它。
3. 在上方函式選單選 `setup` → 執行並授權；再執行 `checkSetup`。這兩個程序不會刪除「互評回覆」。新版採用「互評正式名單2026」儲存 34 位學生及分組；舊「學生名單」保留。
4. 右上角 **部署 → 管理部署**，選原有的「網頁應用程式」→ 鉛筆編輯 → **版本：新版本**；執行身分設 **我**，誰可以存取設 **任何人**，再按「部署」。這一步很重要：僅儲存 `Code.gs` 不會更新學生使用的後端。
5. 在瀏覽器開啟現有的 Apps Script `/exec` 網址。**應看到純文字：**「教學原理互評資料接收端 v7.0 已啟用。學生請回到 GitHub 網頁填寫。」這是教師診斷，不是學生應看到的畫面。
6. 最後到 GitHub 儲存庫，**只替換根目錄的 `index.html`**，提交變更。學生繼續開啟：<https://madspider02.github.io/115-1-tp-peervote/>。

## 如果 `/exec` 仍出現「Google 雲端硬碟目前無法開啟這個檔案」

這表示 **Apps Script 部署網址或存取權限仍有問題**，不是你原本的 GitHub 頁面設計需要改掉。

- 確認你修改的是綁定這份 Google Sheet 的 Apps Script 專案，而且已部署 **新版本**。
- 如果管理部署內沒有可用的舊網頁應用程式，可改用 **部署 → 新增部署 → 網頁應用程式**，設定「以我執行／任何人」，取得一個新的 `/exec` 網址。
- **只有在新網址不同時**，才需修改 `index.html` 的 `WEB_APP_URL` 這一行，貼上新 `/exec` 網址，再重新上傳 GitHub。新版已預填你之前提供的舊網址。
- 當 `/exec` 可以顯示上述 v7.0 的純文字，才表示後端部署可被公開讀取；接下來再測試學生登入及回覆寫入。

## 系統規則

- 第 1、2 組：11/23 報告，11/22 00:00 開放、11/24 23:59 截止，11 位報告組員免填，其他 23 位填。
- 第 3、4 組：12/7 報告，12/6 00:00 開放、12/8 23:59 截止，12 位免填、其他 22 位填。
- 第 5、6 組：12/14 報告，12/13 00:00 開放、12/15 23:59 截止，11 位免填、其他 23 位填。
- 全部是**臺灣時間**。
- 其餘學生每週選該週兩組中的一組，心得**至少 30 字**（不限制為只有 30 字；計算時不計空白字元）。
- 同一學號每週只能交一次，送出後不可修改；下一週可查閱自己已送出的原始心得。

## 技術與測試備註

- `index.html` 保留 v6 原版 CSS、深藍標題、白色卡片與三週分頁。GitHub 不會整頁內嵌 Apps Script，也不會導向 Google Drive。
- Apps Script 以 POST 接收學號、姓名、心得；回覆使用短效隨機代碼取回，**學號、姓名、心得不會放在 GET 網址**。GET 的查詢服務使用 Google 官方文件支援的 JSONP 格式；僅回傳與隨機代碼對應的短效結果。Google Sheet 的 34 人名單留在後端，不放在 GitHub 前端。
- 已用本機模擬測試驗證：34 人核對、免評週、29 字阻擋、30 字以上、長心得、重複送出、歷次回顧與手機版。**還沒有在你的正式線上 Google Sheet 進行實際寫入驗證**；必須由教師更新部署後確認。
- 只用學號＋姓名屬於**簡易辨識**，不是校務系統安全登入；若會計入正式成績，建議增加個人驗證碼或校務帳號。

## 授課教師快速自測

1. 直接打開 `/exec`，確認是 **v7.0 的純文字訊息**，不再是 Google Drive 錯誤。
2. 開啟 GitHub 網頁，確認畫面有學號及姓名兩欄，**沒有跳轉**。
3. 使用已知的課堂資料進入互評頁，**不要用學生身分測試送出**，否則會占掉該生本週唯一的互評機會。
4. 請一位當週應填的學生正常交卷後，到 Sheet「互評回覆」確認完整學號、姓名、報告組別和 30 字以上心得。
