# 教學原理｜跨週次報告互評系統 v6.0（原版介面保留）

這版**保留原本喜歡的深藍色首頁、白色卡片、三週切換、二選一、個人歷次心得**。修復前幾版的錯誤：GitHub iframe 空白、名單表頭衝突、心得 30 字上限、報告者免評、沒有更新部署等。**這套檔案尚未直接連上教師的正式 Google Sheet 完成線上寫入測試**；下方有必要的驗證步驟。

## 三份檔案放哪裡？

| 檔案 | 放置位置 | 功能 |
|---|---|---|
| `Code.gs` | Google Sheet 的「擴充功能 → Apps Script」的程式碼檔 | 核對 34 人、Google Sheet 寫入與查詢、日期規則 |

## 更新順序（最重要）

1. 在原 Google Sheet 開「擴充功能 → Apps Script」。先確認是原本專案，不要另建一份無關的 Apps Script。
2. **將原本 `Code.gs` 的內容完整替換**成這份 `Code.gs`。如果另外有舊檔也定義 `doGet`、`getDashboard`、`submitPeerVote` 或 `setup`，先備份後刪除重複定義；**不要在專案中同時留下多版程式**。
3. Apps Script 左側點 `＋ → HTML`，名稱輸入 `Vote`（不是 `Vote.html.html`）。用這份 `Vote.html` 的內容覆蓋原本 Vote HTML。**Vote 不是放在 GitHub。**
4. 按儲存。從函式下拉選單執行 `setup()`，確認授權；再執行 `checkSetup()`。它應確認「34 位學號姓名匹配」。
5. 「部署 → 管理部署 → 找到目前的**原本網頁應用程式** → 編輯（鉛筆）→ 版本選 **新增版本／新版本** → 部署」。執行身分選「**我**」，存取權選「**任何人**」。請**更新原部署**，避免原 `/exec` 網址指向舊程式。別只按儲存。
6. **先直接開上面 `/exec` 網址。** 右上角應看得到 `v6.0 · 原版設計｜心得至少30字`，也應有學號與姓名輸入欄位。用正式名單中本人資訊執行**查詢**測試；不需要送一筆假的互評。
7. 確認 `/exec` 顯示正常後，才把這份 `index.html` 放到 GitHub 儲存庫根目錄、覆蓋舊檔並 commit。原 GitHub Pages 網址會直接進入相同原版設計的 Apps Script 互評頁。

> 如果 `/exec` 還是舊畫面，不要先換 GitHub：先檢查是否更新了**原本那一筆部署**、是否選了新版本、是否有第二份同名函式。

## 規則與資料保存

- 全班 34 人、6 組，名單已配入 `Code.gs` 後端（不在 GitHub 前端公開）；學生需要輸入**學號與姓名**相互核對。正常使用不需要學生自行登錄名單。
- 11/23 第 1、2 組報告，11/22 00:00 至 11/24 23:59 開放，11 名報告者免評，其他 23 人可填。
- 12/7 第 3、4 組報告，12/6 00:00 至 12/8 23:59 開放，12 名報告者免評，其他 22 人可填。
- 12/14 第 5、6 組報告，12/13 00:00 至 12/15 23:59 開放，11 名報告者免評，其他 23 人可填。
- 日期皆以**臺灣時間**為準；學生只能選擇當週兩組中的**一組**；心得**至少 30 字**，空白不計字數，沒有 30 字上限。
- 每個學號、每週最多一次；送出後只能看自己的歷次心得，**不能回頭編輯**。後端也會限制重複送出、非開放日期、當週報告者填答。
- `setup()` **不刪除**既有「學生名單」及「互評回覆」資料。正式名單另存在「互評正式名單2026」。既有匿名回覆不會被推測連結到學生。`統計總覽` 會按新版公式**重新產生**，如果你先前手動改寫過該統計頁，請先自行備份。

## 原版畫面與防止空白頁的技術安排

- `Vote.html` 保留原版 CSS 與頁面排版；在 Apps Script 的 `/exec` 頂層頁面中使用 `google.script.run` 呼叫後端。
- `index.html` 不再使用 `iframe`。學生仍可從原本 GitHub Pages 網址進入；實際互評頁在 `/exec` 顯示。這是避免 Safari 等瀏覽器攔截跨網站嵌入的方式。
- 開啟 GitHub 網址若未自動跳轉，頁面上仍有「進入互評頁面」按鈕。

## 錯誤排查

| 現象 | 先檢查 |
|---|---|
| GitHub 頁面空白 | GitHub `index.html` 需改成本版，不要保留舊版 iframe |
| 開啟 `/exec` 只顯示舊版 | Apps Script「管理部署」是否編輯**原部署**，建立**新版本** |
| 顯示找不到「學生名單」 | 代表仍執行舊 v4 程式；新版使用「互評正式名單2026」 |
| 輸入學號姓名後查詢失敗 | 檢查部署身分「我」、存取權「任何人」、Apps Script 是否授權，並執行 `checkSetup()` |
| 顯示版本不符 | 必須把 `Code.gs` 和 `Vote.html` 都換成 v6.0 後重新部署 |
| 顯示週次免評 | 代表填寫者本人為當週報告組員，屬正常規則 |

## 資料隱私說明

學號加姓名屬於**名單核對**而不是真正的帳號登入。知道另一位學生的學號與姓名者仍可能查閱或冒名提交，因此**不宜將此系統視為嚴格的身分認證或高風險成績評量**。學生個資不放在 GitHub `index.html` 中；但 Apps Script 後端和 Google Sheet 含有正式名單，請勿將 `Code.gs` 上傳到公開 GitHub。若要嚴格防冒名，需要 Google 帳號授權或每人獨立驗證碼。
