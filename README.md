# 教學原理｜報告互評與跨週心得回顧（2026 / v4 連線版）

## 這份檔案包含什麼
- `index.html`：**已經內建**你提供的 Google Apps Script `/exec` 網址，不必再自行填入。
- `Code.gs`：配套的 Google Apps Script 後端（與 v2/v3 訊息格式相容；如果你的後端是舊的匿名版，必須先更新）。
- 學生填寫時，**學號、姓名兩欄必填**。只有查詢成功才會開啟互評頁面。
- 同一學號每週最多一次；兩組擇一；30 字內心得；後續可查看以前的心得但不可修改。

## 真正上線只要做這兩件事

1. **GitHub 網頁**：打開 `https://github.com/madspider02/115-1-tp-peervote`，把這份 `index.html` 完整覆蓋儲存庫根目錄原有的 `index.html`（保持檔名一致）。等 GitHub Pages 更新後，開啟 `https://madspider02.github.io/115-1-tp-peervote/`。標頭應顯示 **「v4 · 已設定 Sheet 連線」**。
2. **Apps Script 後端**：請在這門課的 Google Sheet → 擴充功能 → Apps Script 檢查程式。如果還不是本包的 `Code.gs`（應含 `doPost`、`studentId`、`studentName`、`setup`），完整貼上本包的 `Code.gs`；執行 `setup()`。從「部署 → 管理部署 → 編輯」設定**執行身分：我；存取權：任何人**，版本選**新版本**後按「部署」。這樣原本 `/exec` 網址才會使用最新的後端程式。

> 如果你在 Apps Script 重新選「新增部署」，有可能產生不同的 `/exec` 網址，屆時需同步更換 `index.html` 中的 `WEB_APP_URL`。建議使用「管理部署」更新原有部署。

## Sheet 資料欄位
`互評回覆` 表會記錄：提交時間、報告日期、週次、**學號、姓名**、獲選組別、報告主題、心得、提交編號。
`學生名單` 表預載六組成員姓名，可在 B 欄補登學號，讓系統比對學號與姓名。此表**不要上傳到公開 GitHub**。
`統計總覽` 表會計算當週各組得票數與得票比例。

## 上線檢查（請務必實測，不可只看畫面）
1. 在正式網頁填入自己的**已列入學生名單**的學號和姓名（或由教師暫時在 Sheet 加一筆測試名單）。
2. 按「查看我的互評頁面」，確認不再顯示「尚未連接 Google Sheet」，而是進入互評與心得回顧介面。
3. 在開放期間測試送出，確認 Sheet 的 `互評回覆` 列有**相同的學號、姓名**；同一個學號再次進入，只看到已送出心得，不可重新送出。
4. 測試完畢可由教師在 Sheet 中刪除自建測試名單及測試回覆列（**不要誤刪真實學生資料**）。

## 安全與限制
- 我們只能根據已提供的程式檢查設定及在本機模擬前後端互動；**無法從這裡讀取你的私人 Google Sheet 或證明當前 `/exec` 已部署最新版**。上線時需要你完成上述一次實測。
- 學號＋姓名不是正式登入驗證。知道別人的學號和姓名可能冒名查詢。若是計分用途，可再加個人驗證碼或學校帳號身分驗證。
- 請不要把 Google Sheet 設為公開可編輯，並遵守校內學生資料保護要求。
